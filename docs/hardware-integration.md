# 硬件接入说明

本文件定义未来适配的接口约定。当前仓库不提供串口驱动、CAN 驱动或可直接部署到实机的控制进程。

## 建议接口

| 输入/输出 | 字段 | 单位及约束 |
| --- | --- | --- |
| 上层速度输入 | v, w, monotonic_timestamp | m/s、rad/s、单调时钟秒；与控制循环同一时钟域 |
| 编码器反馈 | left_position, right_position, timestamp | rad；解包计数溢出后计算速度 |
| 障碍反馈 | nearest_clearance, timestamp, valid | m；须明确机器人外轮廓与传感器原点的变换 |
| 急停输入 | emergency_active | 布尔值，硬件链路独立于上位机 |
| 电机输出 | left_effort, right_effort | [-1, 1]，适配层映射为设备协议 |

`SafetyGate.filter` 支持上层指令超时，但当前没有传感器数据超时检查。适配层必须在调用前验证编码器与距离传感器的新鲜度；失联时应进入停机流程。仿真中的无限距离表示无遮挡的合成输入，不能把未知的传感器状态解释为无限安全距离。

## 接入顺序

1. 测量实际轮半径与轮距，确认轮速单位、左右轮方向和编码器计数转换关系。
2. 独立实现设备通信、超时处理、错误码解析及硬件急停链路。
3. 架空底盘，以低输出核对每个车轮正转方向，再分别辨识响应与摩擦死区。
4. 建立受限速度测试环境，整定轮速控制参数，记录速度阶跃响应。
5. 测量载荷、地面条件与速度下的最坏制动距离，加入传感延迟和通信延迟裕量。
6. 完成故障注入与里程计校准后，再接入上层导航。

## URDF 参考模型

`robot/alpha.urdf` 包含 base_footprint、base_link、左右连续轮关节及后支撑球。轮半径与轮距和默认控制配置一致。URDF 仅用于结构表达与后续可视化，没有控制插件、传感器插件或 Gazebo 场景，也未进行动力学仿真验证。

若增加 ROS 2 封装，可将速度输入映射到 `geometry_msgs/Twist`、里程计映射到 `nav_msgs/Odometry`，并维护 odom → base_footprint 的变换。此映射为后续设计，当前没有发布相应话题。
